## 팀 구성

| 팀 | 구성 |
| --- | --- |
| 🟢 찰떡 팀 | 찰떡 팀장 · 아기곰 차장 · 노랑냥 과장 · 병아리 인턴 |
| 🐰 뮤즈 팀 | 뮤즈 팀장 · 여우 대리 · 판다 대리 · 펭귄 인턴 |

- 두 팀장(찰떡·뮤즈)은 **동등한 공동 팀장**입니다.
- 8명 각자 자기 팀 구역의 전용 책상·의자에 앉아 있고, 말풍선은 5초마다 한 명씩 돌아가며 표시됩니다(겹침 방지).
- 상단 **🗣️ 회의하기** 버튼 → 안건 입력(추천 칩 6개 + 자유 입력) → 8명이 8인 원탁 의자로 걸어가 착석하고,
  안건 키워드에 맞춘 9턴 회의가 말풍선 + `📡 실시간 회의 중계 · 회의록`에 한 줄씩 쌓입니다.
- 회의록은 **📥 이 안건 비서실에 전달**(GitHub 비공개 이슈)로 바로 넘길 수 있고,
  **회의 종료 (자리로 복귀)** 를 누르면 각자 자리 의자로 돌아갑니다.

## 실시간 상태 (`status.json`)

페이지는 `status.json?t=...` 을 **15초마다** 읽어 8명 요원의 말풍선을 갱신합니다.

```json
{
  "mode": "working",                  // idle | meeting | working
  "task": "아침 경제 브리핑 1편 팩트체크 & 대표 이미지 생성 중",
  "agenda": "오늘 발행 3건 확정 회의",   // meeting 모드에서만 사용
  "updated_at": "2026-11-28T06:40:00+09:00",
  "expires_at": "2026-11-28T07:05:00+09:00",   // 지나면 자동으로 시간대별 기본 근무로 복귀
  "characters": {
    "chaldeok": { "room": "command", "bubble": "발행 3건 최종 점검 중!", "detail": "경제 브리핑·낮 유입글 발행 완료", "active": true }
  }
}
```

- 캐릭터 키 8명: `chaldeok`(팀장) · `muse`(팀장) · `bear`(차장) · `cat`(과장) · `fox`(대리) · `panda`(대리) · `chick`(인턴) · `penguin`(인턴)
- `mode=meeting` 이면 8명이 원탁 의자로 모여 말풍선을 돌아가며 주고받고,
  `mode=working` 이면 각자 전용 책상 의자에 앉아 `bubble`/`detail` 을 보여줍니다(방 지정은 v9 호환용으로만 남아 있음).
- 목록에 없는 캐릭터는 `active:false` 를 주지 않는 한 자기 자리에 기본 말풍선으로 남습니다.
- **이 파일은 공개됩니다.** 실명·주소·직장·계정 같은 사적 정보는 절대 넣지 말고 업무 내용만 구체적으로 적으세요.
- 발행은 `set_status.py` 로 합니다(로컬 파일 갱신 + `main`·`gh-pages` 에 `status.json` 만 푸시, 보통 1~2초).
  GitHub Pages 빌드 때문에 라이브 반영까지는 20~30초 더 걸릴 수 있습니다.
